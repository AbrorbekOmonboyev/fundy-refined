FUNDY BRAND KIT
Version 1.0, November 2026

WHAT'S INSIDE

Fundy-brand-sheet.pdf   One page with the logo, colours, fonts and the main rules.

01-Logo
  Horizontal   The main logo. Use this one most of the time.
  Stacked      The f above the name, for square spaces.
  Symbol       The layered f on its own, for avatars, stickers and small spaces.
  Wordmark     The name on its own, for when the f already appears nearby.

  Each logo comes in five colour versions:
    light           for white or light backgrounds (the default)
    on-chartreuse   for chartreuse backgrounds
    dark            for ink or dark photo backgrounds
    black / white   single colour, for stamps, engraving, fax or one-colour print

  File types:
    SVG   websites, apps, Figma, Canva. Sharp at any size.
    PDF / EPS   printers, sign makers, merchandise.
    PNG   Word, PowerPoint, Google Docs, anywhere else. Transparent background.

02-App-icon
  iOS/AppIcon-1024.png        Upload this to Xcode or App Store Connect. Apple rounds the corners itself.
  iOS/AppIcon-1024-dark.png   Dark mode version.
  Android/play-store-512.png  Google Play listing icon.
  Android/adaptive/           Foreground, background and monochrome layers (432 x 432) for the Android launcher icon.
  Rounded-previews/           Icons with rounded corners, for decks, websites and mockups.

03-Favicon
  Put these files in your website's root folder and paste the lines from add-to-website.html into the page head.

04-Social-media
  Profile/   Profile pictures. They work for Instagram, Facebook, LinkedIn, X, YouTube, TikTok and Telegram, and stay safe inside a circle crop.
  Banners/   Covers at each platform's recommended size, plus @2x versions for sharp screens.
               LinkedIn company page 1128 x 191, LinkedIn personal 1584 x 396, X 1500 x 500,
               Facebook 851 x 315, YouTube 2560 x 1440 (text kept inside the 1546 x 423 safe area).
  Posts/     Instagram posts (1080 x 1350 and 1080 x 1080), a story (1080 x 1920), a campaign template and a link preview (1200 x 630).
             Text in square brackets is a placeholder, so replace it before posting.

05-Colours
  fundy-colours.txt   All colour codes.
  fundy-colours.css   Colour variables for developers.

COLOURS
  Chartreuse     HEX #B5F23D   RGB 181, 242, 61   CMYK 38, 0, 89, 0
  Ink            HEX #15122B   RGB 21, 18, 43   CMYK 95, 80, 0, 89
  Shadow green   HEX #90D508   RGB 144, 213, 8   CMYK 51, 0, 99, 0
  White          HEX #FFFFFF   RGB 255, 255, 255   CMYK 0, 0, 0, 0

  The CMYK values are for coated paper (FOGRA39). Chartreuse is brighter on screen than any CMYK print can be,
  so for business cards and posters ask the printer to match it to a Pantone spot colour and show you a proof first.

FONTS
  Unbounded Bold for headlines: https://fonts.google.com/specimen/Unbounded
  Plus Jakarta Sans for everything else: https://fonts.google.com/specimen/Plus+Jakarta+Sans
  Both are free to use, including commercially. The logo files already have the lettering turned into shapes,
  so they look right even on computers without these fonts.

SIMPLE RULES
  - Keep at least half the logo's height clear on every side.
  - Don't make the horizontal logo narrower than 100 px on screen or 25 mm in print.
  - Don't stretch, rotate, recolour or add effects to the logo. Use one of the five versions instead.
  - Chartreuse is a background and highlight colour. Use ink for text, including text on chartreuse.
  - On white pages, make buttons ink. Chartreuse alone is too light against white.
